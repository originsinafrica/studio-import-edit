# Project Showcase Studio

Crée-moi un site avec la présentation de ce projet de studio. Hyper classe, hyper élégant, assez dynamique, avec le contenu que je te partage là. À toi d'arranger le positionnement, les textes, etc. Pas obligé de faire plusieurs pages, tu peux en faire peut-être une ou deux, je n'en sais rien, c'est à toi de voir. Je te partage aussi deux dossiers de présentation des projets qui vont être intégrés. Ne tiens pas compte des budgets qui sont dans les dossiers PDF. C'est juste pour te montrer l'univers dans lequel nous allons évoluer.

This project was built with [Lovable](https://lovable.dev).
